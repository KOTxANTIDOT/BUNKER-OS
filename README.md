# 🐈‍⬛ БУНКЕР КОТА
### OVERDRIVE · Android VPN & Config Lab

**Собственный Android-клиент и рабочее место для подготовки VPN-конфигураций.**

## Что это

Бункер Кота: OVERDRIVE — отдельная версия Android-клиента на базе открытого проекта Throne for Android. Мы сохраняем проверенные сетевые компоненты и развиваем собственный интерфейс, инструменты импорта, обработки и проверки конфигураций.

## Что уже есть в основе

- VPN-режим и proxy-only режим.
- Движки sing-box и Xray.
- Поддержка VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard и других протоколов.
- Импорт ссылок, подписок и конфигураций.
- Массовый URL-test: прогресс, задержка, гистограмма, список лучших серверов.
- Сортировка по результатам, удаление недоступных и подключение к самому быстрому.
- Маршрутизация по приложениям, доменам, IP и правилам.
- Резервное копирование конфигураций.

## Направление OVERDRIVE

1. Собственный визуальный стиль Бункера Кота.
2. Отдельный экран парсера: вставка текста, импорт TXT и подписок.
3. Нормализация ссылок, фильтрация мусора и дублей.
4. Геоопределение и единый нейминг серверов.
5. Очередь проверок с настройкой потоков, тайм-аутов и лимитов.
6. Экспорт отсортированных результатов в TXT и форматы подписок Бункера.

## Сборка

Проект собирается через Gradle и GitHub Actions. Для release-подписи используются секреты GitHub Actions:

- `SIGNING_KEYSTORE_B64`
- `SIGNING_STORE_PASSWORD`
- `SIGNING_KEY_ALIAS`
- `SIGNING_KEY_PASSWORD`

ABI выпускаются отдельными APK: arm64-v8a, armeabi-v7a и x86_64.
