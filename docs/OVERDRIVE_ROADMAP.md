# Бункер Кота: OVERDRIVE — план работ

## Принципы

- Разработка только в ветке `feature/bunker-overdrive`.
- `main` не изменять.
- Не переписывать сетевое ядро и работающий URL-test без технической причины.
- Сначала завершать связанный набор изменений, затем запускать одну общую сборку и проверку.
- Не удалять upstream copyright notices и соблюдать GPL-3.0.

## Что уже присутствует в основе

- sing-box и Xray.
- Импорт серверных ссылок и подписок.
- Массовый URL-test с живым прогрессом, гистограммой задержки и рейтингом рабочих серверов.
- Действия после теста: подключение к лучшему, сортировка и удаление недоступных.
- Маршрутизация и правила приложений.
